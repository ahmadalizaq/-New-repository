# موقع مودولا — وحدات سكنية جاهزة

كتالوج بـ 86 وحدة، لكل وحدة صفحة مستقلة ومجسّم ثلاثي الأبعاد ملوّن بنمط
بناء خاص بها، وسلة اختيارات ترسل طلب عرض سعر على واتساب.

## البنية
```
index.html                 الصفحة الرئيسية
unit/CP-13.html            صفحة مستقلة لكل وحدة (86 صفحة)
unit/fonts.css
assets/site.css            التنسيقات
assets/data.js             بيانات الوحدات: أبعاد وألوان وأنماط وصور
assets/viewer.js           العارض ثلاثي الأبعاد ومكتبة أنماط البناء
assets/app.js              الفلاتر وسلة الاختيارات والحركات
assets/unit.js             منطق صفحة المنتج
assets/three.min.js        مكتبة العرض ثلاثي الأبعاد
assets/gltf-loader.min.js  محمّل ملفات .glb من الموردين
assets/models/             ضع هنا ملفات الموردين ثلاثية الأبعاد
assets/img/                الصور
assets/fonts/              الخطوط العربية
```

## قبل النشر — عدّل سطرين

الرقم واسم الشركة مكرران في كل صفحة داخل وسم `<script>` قرب النهاية:

```js
var CFG={whatsapp:"965XXXXXXXX",brand:"مودولا", ... }
```

استبدلهما دفعة واحدة من الطرفية:

```bash
grep -rl '965XXXXXXXX' . | xargs sed -i 's/965XXXXXXXX/96599112233/g'
grep -rl 'مودولا' . | xargs sed -i 's/مودولا/اسم شركتك/g'
```

على ويندوز، استخدم "بحث واستبدال في كل الملفات" في VS Code.

الرقم بالصيغة الدولية بدون + وبدون أصفار بادئة. مثال كويتي: `96599112233`.

## الرفع

ملفات ثابتة فقط، بلا خادم ولا قاعدة بيانات.
ارفع محتويات المجلد كما هي على Netlify أو Cloudflare Pages أو GitHub Pages
أو أي استضافة عادية.

مهم: احتفظ بمجلد `unit/` بجانب `index.html` — روابط صفحات المنتجات
تعتمد على هذا الترتيب.

## المجسّم ثلاثي الأبعاد

كل الوحدات الـ86 لها مجسّم، يُبنى لحظياً في متصفح الزائر من ثلاثة حقول
في `assets/data.js`.

### `arch` — نمط البناء

أُسنِد لكل وحدة بعد مراجعة صورتها الفعلية. الأنماط المتاحة:

| النمط | الشكل |
|---|---|
| `pod` | كبسولة مدبّبة بزجاج ملتفّ وشريط لوني |
| `pod2` | كبسولتان فوق بعض مع تراس ودرابزين ودرج خارجي |
| `drum` | كبسولة أسطوانية بشريط زجاجي وقبة مسطّحة |
| `aframe` | خيمة مثلثة بواجهة زجاجية وشرفة |
| `expand` | حاوية مضلّعة بجناحين يتوسّعان |
| `container` | حاوية شحن مضلّعة بأعمدة زوايا |
| `house` | بيت بطابق واحد بسقف هرمي ومدخل مظلّل |
| `cabin` | كابينة خشبية بسقف جملوني حادّ وواجهة زجاجية مثلثة وشرفة |
| `villa2` | فيلا بطابقين ببلكونة وسقف مائل |
| `block` | مبنى متعدد الطوابق بأشرطة أرضيات وشبكة نوافذ وسور سطح |
| `shed` | صالة بسقف مقوّس على أعمدة |
| `dome` | قبة جيوديسية زجاجية بأضلاع ظاهرة |

لتغيير نمط وحدة، عدّل `"arch":"cabin"` في `assets/data.js`.

### `geo` — الأبعاد

```js
"geo":{"shape":"box","l":11.5,"w":3.3,"h":3.3}
"geo":{"shape":"dome","d":6}
```

للمباني متعددة الطوابق، `h` هو ارتفاع الطابق الواحد وعدد الطوابق يؤخذ
من `stories`.

### `pal` — الألوان

مستخرجة آلياً من صورة المنتج نفسها:

```js
"pal":{"shell":"#E5DCD0","shell2":"#CFC6B8","glass":"#1C1E1F",
       "accent":"#D14A17","roof":"#6B5A4A"}
```

`shell` الهيكل · `shell2` الطابق العلوي والعناصر الثانوية ·
`glass` الزجاج · `accent` الإطارات والشرائط والدرابزين · `roof` السقف.

الاستخراج الآلي يخطئ أحياناً، خصوصاً مع الصور التوضيحية بدل الفوتوغرافية.
عدّل الحقل يدوياً وقتها.

### الأبعاد التقديرية

24 وحدة — أغلبها مبانٍ متكاملة — ليست أبعادها في الملف الأصلي، فقُدِّرت
من المساحة وعدد الطوابق ووُسمت بـ `"est":true`. الموقع يخبر الزائر بذلك
داخل العارض ويكتب "الأبعاد (تقديرية)" في جدول المواصفات.

متى حصلت على الأبعاد الحقيقية، ضعها في `geo` واحذف `"est":true`.

### حدود المجسّم البرمجي

نموذج كتلي بمقياس رسم — دقيق في الأبعاد والنسب واللون والشكل العام،
لكنه لا يُظهر تفاصيل التشطيب الفعلية. للتطابق التام، انظر القسم التالي.

## التطابق التام: ملفات الموردين

اطلب من المورّد ملفه ثلاثي الأبعاد — أغلب المصانع تملك ملفات SketchUp أو
3ds Max وتشاركها لأنها تساعدها على البيع.

اطلب صيغة **`.glb`** تحديداً، أو حوّل إليها مجاناً من Blender. ثم:

1. ضع الملف في `assets/models/` باسم الوحدة، مثلاً `CP-13.glb`.
2. أضف السطر التالي إلى تلك الوحدة في `assets/data.js`:

```js
"glb":"../assets/models/CP-13.glb"
```

الموقع يحمّله تلقائياً، يضبط مقياسه على الأبعاد المسجّلة، ويستبدل به
النمط البرمجي. لو فشل التحميل لأي سبب، يبقى النمط البرمجي ظاهراً فلا
تنكسر الصفحة أبداً.

عند استبدال وحدة بملف حقيقي، احذف الملاحظة التي تقول إن المجسّم تقريبي:
السطر الذي يبدأ بـ `u-note3d` في `assets/unit.js`.

## استبدال الصور

الصور الحالية مأخوذة من صفحات الموردين وعلى أغلبها علاماتهم المائية.
لاستبدال صورة، ضع الجديدة في `assets/img/` بنفس الاسم وبمقاسين:
`imageNN.webp` (عرض 1200 بكسل) و `imageNN_t.webp` (عرض 560 بكسل).
لإضافة صور جديدة لوحدة، أضف أسماءها إلى مصفوفة `imgs` الخاصة بها في
`assets/data.js`.

ملاحظة: ألوان المجسّمات مستخرجة من الصور الحالية. إن استبدلت الصور،
عدّل الحقل `pal` يدوياً ليطابق الألوان الجديدة.

## الأسعار

لا يعرض الموقع أي سعر عمداً. ملف المصادر يحتوي أسعار تكلفة وأسماء
موردين وروابط علي بابا؛ نشرها يكشف هامش ربحك. كل وحدة تعرض زر
"اطلب عرض سعر" بدلاً من ذلك.
